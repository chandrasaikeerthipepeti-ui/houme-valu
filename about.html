BEHIND THE ESTIMATE

How the model works

HomeValue is a student demonstration project that uses supervised machine learning to estimate residential property prices.

01

Dataset

7,000 generated sample records across 30 Indian cities. The records are synthetic and are not collected from property transactions.

02

Features

City, built-up area, bedrooms, bathrooms, property age, furnishing, parking and locality category.

03

Algorithm

A Random Forest Regressor learns relationships between the property features and the generated sample prices.

Important limitation

The dataset is synthetic, created for demonstrating an end-to-end ML workflow. Model scores only measure performance on similarly generated data. Predictions should not be used to make real buying, selling, lending or investment decisions. Replace the demo dataset with verified, recent local transaction data before any real-world use.
